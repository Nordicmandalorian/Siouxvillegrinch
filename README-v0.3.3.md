# Siouxville Grinch v0.3.3 — TikTok Pics

This patch changes only the **TikTok Pics** feature under **Bored?**.

- Bundles all 12 supplied TikTok images inside the app under `public/tiktok-pics/`.
- TikTok Pics now opens a native in-app gallery instead of relying on external image hosting.
- Tapping an image opens an in-app full-screen viewer; tapping again closes it.
- Booking, Grinchmail, Coloring Book, Media, Reviews, Sponsorship, and other features are unchanged.
