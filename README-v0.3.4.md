# v0.3.4 — Coloring Pages

This patch changes only the Coloring Book feature.

- Bundles all 20 supplied coloring pages locally in `public/coloring-pages/`.
- Connects **Bored? → Color a Grinch** to a native in-app gallery.
- Tapping a page opens the full image in the existing in-app lightbox style.
- No Media / Media Coverage fixes are included in this patch.
